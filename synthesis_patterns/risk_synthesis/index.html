🔴 Critical Risks (P0 - Fix Immediately)

1. Credentials in Plain Text (Database Password)

Severity: CRITICAL | Likelihood: High | Impact: Critical

Description: Database password `4YbeUrM2bD` visible in application.properties files (from Security Analysis)

Business Impact:

  • Unauthorized database access (anyone with code access gets DB credentials)
  • Data breach: All citizen identity data exposed
  • Compliance violation: Fines up to 10% revenue
  • Liability: Breach notification costs + reputational damage
Mitigation:
  • Move credentials to environment variables (immediate, same day)
  • Rotate database password immediately
  • Use HashiCorp Vault or AWS Secrets Manager for long-term
  • Audit git history for exposed credentials
Timeline: 4 hours | Cost: $5K

2. Missing Input Validation

Severity: CRITICAL | Likelihood: High | Impact: High

Description: Controller endpoints accept parameters without @Valid, null checks, or type validation (from Security Analysis)

Business Impact:

  • Injection attacks: SQL injection, expression language injection possible
  • NullPointerException crashes: Service unavailability
  • Type coercion attacks: Unexpected behavior with malformed input
Mitigation:
  • Add @Valid on all DTOs
  • Implement JSR-303 constraints (@NotNull, @Size, @Pattern, etc.)
  • Add null checks in service layer
Timeline: 3-4 days | Cost: $3K

3. No Rate Limiting

Severity: CRITICAL | Likelihood: Medium | Impact: High

Description: No protection against API abuse or distributed denial-of-service attacks (from Security Analysis)

Business Impact:

  • Denial of Service: Attacker can exhaust service with high-volume requests
  • Credential brute-force: Attacker can attempt to guess/enumerate credentials
  • Service disruption: Legitimate users get degraded service
Mitigation:
  • Implement Spring Cloud Gateway rate limiting (requests/user/minute)
  • Add @RateLimiter on critical endpoints
  • Use Redis for distributed rate limiting (across instances)
Timeline: 3-5 days | Cost: $2K

4. Sensitive Data in Logs

Severity: CRITICAL | Likelihood: High | Impact: High

Description: Stack traces include credentials; database credentials logged as strings (from Security Analysis)

Business Impact:

  • Credential exposure via log aggregation tools (ELK, CloudWatch, etc.)
  • Compliance violation: PII protection regulations
  • Supply chain risk: 3rd-party log analysis tools may have access
Mitigation:
  • Implement log masking: Replace sensitive patterns (passwords, API keys)
  • Use Logback filters to exclude sensitive fields
  • Don't log full stack traces; use structured logging with sanitization
Timeline: 2-3 days | Cost: $2K

5. All Errors Return HTTP 200

Severity: CRITICAL | Likelihood: High | Impact: Medium

Description: ApiExceptionHandler returns HTTP 200 even for 403 Forbidden, 500 Internal Server Error (from Security Analysis)

Business Impact:

  • Violates HTTP standards; breaks client error handling
  • Makes debugging harder: Status codes are reliable indicators
  • Masks real errors: Clients can't distinguish success from failure
  • Security: Attackers can't detect which requests failed
Mitigation:
  • Return correct HTTP status codes: 400 (Bad Request), 403 (Forbidden), 500 (Server Error)
  • Update ApiExceptionHandler to map exceptions to proper status codes
Timeline: 1 day | Cost: $1K

Total P0 (Critical) Effort: 10 days | Estimated Cost: $13K
Business Impact if Not Fixed: Regulatory breach, data loss, service disruption

🟠 High Risks (P1 - Fix within 2 weeks)

1. No Request Timeouts (External Service Calls)

Severity: HIGH | Likelihood: Medium | Impact: High

Description: RestTemplate calls to external services (KeyManager, DataShare, Credential Service) have no timeout (from Security Analysis)

Business Impact:

  • Thread exhaustion: Requests hang indefinitely; thread pool gets exhausted
  • Cascading failure: If external service is slow, entire card generation fails
  • Resource leak: Threads never released; memory usage grows unbounded
Mitigation:
  • Set connectTimeout: 5 seconds
  • Set readTimeout: 10 seconds
  • Configure RestTemplate with HttpComponentsClientHttpRequestFactory
Timeline: 1 day | Cost: $1K

2. No Circuit Breaker (External Dependencies)

Severity: HIGH | Likelihood: Medium | Impact: High

Description: If KeyManager, DataShare, or Credential Service are unavailable, service will fail completely (from Security Analysis)

Business Impact:

  • No graceful degradation: All credential issuance fails
  • Cascading outage: One external service down = entire platform down
  • Slow recovery: No automatic retry or fallback
Mitigation:
  • Implement Resilience4J circuit breaker
  • Implement retry logic (3 attempts, exponential backoff)
  • Implement fallback strategy: Queue credential for async retry
Timeline: 3-4 days | Cost: $2K

3. Caching Disabled (Performance Bottleneck)

Severity: HIGH | Likelihood: High | Impact: High

Description: Hibernate L2 cache disabled; every request hits database (from Performance Analysis)

Business Impact:

  • Database load: 50-100 queries per operation (one per request)
  • Latency: 50% of response time from database round trips
  • Scalability ceiling: Database becomes bottleneck at ~50 concurrent requests
Mitigation:
  • Phase 1: Enable Hibernate L2 cache with EhCache (immediate)
  • Phase 2: Switch to Redis for distributed cache (Month 1)
  • Expected improvement: 50% latency reduction
Timeline: 2-3 days (Phase 1) | Cost: $2K

4. Single Replica Deployment (HA Risk)

Severity: HIGH | Likelihood: High | Impact: High

Description: Single instance with no redundancy; no horizontal auto-scaling (from Deployment Analysis)

Business Impact:

  • Single point of failure: Pod crash = complete service outage
  • Maintenance downtime: Rolling updates cause outages
  • Cannot handle load spikes: Manual scaling too slow
  • SLA failure: Can't meet 99.9% uptime target
Mitigation:
  • Deploy minimum 3 replicas
  • Enable HPA: Scale from 3-10 replicas based on CPU load (70% target)
  • Update PDB (Pod Disruption Budget) to maintain ≥1 replica during maintenance
Timeline: 2-3 days | Cost: $3K

5. Small Thread Pools (Concurrency Bottleneck)

Severity: HIGH | Likelihood: High | Impact: High

Description: Thread pools limited to 2-5 threads; request queueing under load (from Performance Analysis)

Business Impact:

  • Request queue overload: >50 concurrent requests causes exponential latency increase
  • Throughput ceiling: Can't exceed ~50 concurrent requests
  • Scalability bottleneck: Blocks 20x growth target
Mitigation:
  • Increase scheduling thread pool: 2 → 20 threads
  • Increase application thread pool: 5 → 50 threads
  • Monitor thread utilization; adjust based on peak load
Timeline: 1 day | Cost: $500

Total P1 (High) Effort: 12 days | Estimated Cost: $8.5K
Business Impact if Not Fixed: Service outages, poor performance, limited scalability
