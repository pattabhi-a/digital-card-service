Scalability Roadmap

  • Phase 1: Enable Hibernate L2 cache + increase thread pools (2 weeks)
  • Phase 2: Implement async PDF generation; add HPA (1 month)
  • Phase 3: Distributed caching (Redis); database read replicas (2 months)
  • Phase 4: Database partitioning; event streaming (Kafka) (3 months)

🎯 Availability Requirements

Requirement Target SLA Current Capability
Uptime 99.9% (8.76 hours/year downtime) ~95% (single replica, no HA)
RTO (Recovery Time) < 5 minutes ~1-2 minutes (Kubernetes restart)
RPO (Recovery Point) No data loss Depends on database backup strategy
Failover Capability Automatic ⚠️ Manual (no replica setup)

Recommendations for 99.9% SLA

  • Deploy 3-5 replicas across availability zones
  • Implement Pod Disruption Budget (PDB)
  • Set up database read replicas with automatic failover
  • Configure Redis cluster for distributed caching
  • Implement circuit breaker for external service calls
  • Test disaster recovery monthly
