🚨 Performance Bottlenecks

CRITICAL: Caching Disabled (Hibernate L2 Cache)

Every request hits database; no caching for template and identity lookups.

Impact: High database load; increased latency; poor resource utilization.

Recommendation: Enable Hibernate L2 cache (Redis or EhCache); estimated 50% latency reduction.

HIGH: Small Thread Pools (2-5 threads)

SchedulingConfigurerConfiguration: size 2; DigitalCardApplication: size 5. Limited concurrent processing.

Impact: Request queuing under load; bottleneck at ~50-100 concurrent requests.

Recommendation: Increase pool size to 20-50 based on CPU cores and expected load.

HIGH: Synchronous PDF Generation

PDFCardServiceImpl blocks thread during PDF generation (est. 500ms-2sec per card).

Impact: Thread starvation under burst loads; cascading timeouts.

Recommendation: Implement async PDF generation with task queue (RabbitMQ, Kafka, SQS).

MEDIUM: No Connection Pooling Configuration

Hibernate default pool settings; unbounded connection creation possible.

Impact: Connection exhaustion under load; database connection limits exceeded.

Recommendation: Configure HikariCP: minPoolSize=10, maxPoolSize=20; idleTimeout=300s.

MEDIUM: Sequential Event Processing

Events processed one at a time; no batching or parallelization.

Impact: Can't handle burst events (e.g., bulk credential issuance).

Recommendation: Implement batch processing; parallel event handlers.

🎯 Performance Optimization Roadmap

Quick Wins (1-2 weeks)

  • Enable Hibernate L2 Cache - Estimated 50% latency reduction for identity/template lookups
  • Configure Connection Pooling - HikariCP with appropriate pool size
  • Increase Thread Pool Sizes - From 5 to 20-50 threads
  • Add Database Query Indexes - On RID, status fields

Medium-term (1 month)

  • Async PDF Generation - Offload to task queue; reduce thread blocking
  • Batch Event Processing - Handle bulk credential issuance efficiently
  • Add Metrics Collection - Micrometer + Prometheus for performance monitoring
  • Implement CDN Caching - For DataShare-hosted PDFs

Long-term (2-3 months)

  • Distributed Caching - Redis for cross-instance cache sharing
  • Database Partitioning - By region or tenant (if multi-tenant)
  • GraphQL API - For selective field queries; reduce payload
  • Load Testing - Establish SLAs and capacity plans
