ADR-001 — WebSub for credential lifecycle events
Status
Accepted (in code).
Context
Service must react to identity create/update and credential-ready events from Registration Processor and Credential Service.
Decision
Use MOSIP kernel WebSub publisher/subscriber with HMAC intent verification (controller:49,64,79).
Alternatives
Polling, Kafka direct.
Consequences
Loose coupling; relies on hub re-delivery; current code swallows errors blocking re-delivery (controller:56).
Evidence
DigitalCardController.java:47-98; DigitalCardInitializer.java:88-101.
ADR-002 — PostgreSQL via JPA for transaction state
