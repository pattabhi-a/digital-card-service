Security Analysis

TL;DR
  • Plaintext secrets in application-local1.properties: DB password, IAM client secret, WebSub secret.
  • All exception responses return HTTP 200 (ApiExceptionHandler:48,54,98) — clients cannot detect failure.
  • Sensitive data leak: DB username concatenated into ERROR log on credential failure (controller:93).
  • WebSub HMAC verification present via @PreAuthenticateContentAndVerifyIntent (controller:49,64,79) — good.
  • Encryption delegated to external CryptoManager via EncryptionUtil.decryptData — no in-process key material; positive.

Positive Controls
